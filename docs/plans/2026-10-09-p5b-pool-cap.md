# Package 5b: Per-hook pool cap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `v4_pools` stops growing by one row per launchpad coin. A hook keeps at most `INDEXER_POOLS_PER_HOOK` (2,000) rows; past that its pools are counted, not stored, and the true pool count stays known. A pool past the cap that swaps still becomes a row, so no swap is lost. A one-time CLI trims the excess that is already there.

**Architecture:** One additive migration (`0013`) mirrored in `db.py`: `v4_pools.sampled`, table `hook_pool_counts`, `hooks.pools_total`. The Initialize page applies the cap in its own transaction (`store.store_pools`, before the upsert): a hook past the cap gets a `hook_pool_counts` row whose `pools_total` is every pool of the hook, stored or not, and only Initialize blocks after its `last_block` are counted, so a page seen twice is counted once. In swap scan mode, pool ids that are not rows are resolved by `core.PoolResolver` (per chain, kept by the Runner): first from the rows this process left out, then by one HyperSync Initialize query by pool id (topic1) over `[floor, page end)` per 500 ids, at most `INDEXER_POOL_LOOKUPS` calls per chain per loop, with a negative cache for unhooked pools. Resolved pools are inserted with `sampled = true` in the swap page's transaction, after the compare-and-set. The nightly `onchain` step writes `hooks.pools_total`; `score` reports `pools_n` as at least that. `python -m bait.indexer prune-pools` deletes idle rows of hooks over N under the chain's advisory lock.

**Tech Stack:** Python 3.12, SQLAlchemy 2 Core, psycopg 3, httpx, pytest. Postgres 15+ for `tests/test_postgres.py`.

**Spec:** Disk incident of 2026-10-09: `v4_pools` ~5.9M rows (~550 B each), the Base backfill adding ~43K hooked pools per 8-minute loop, 44 of 56 hooked Initialize logs in a 500-block sample at the Base head from one launchpad hook (`0x0469a4bd...50c0`), Postgres 3.6 GB -> 12.4 GB in a day.

**What the code says that the brief did not (judgment calls):**
1. `hook_pool_counts.pools_total` is the hook's *true total* (stored rows plus the rest), not the count of pools left out. A late (sampled) insert or a prune then changes no counter, and the nightly step reads one number. One extra column, `first_block` (oldest pool that is not a row), is the floor of the HyperSync lookup.
2. The cap keeps the *first* N pools to arrive (block order during a backfill), as "applied in arrival order, no eviction" implies; the prune keeps the *newest* N. Both keep every pool that ever swapped.
3. `project_daily.pools_n` counts pools with a snapshot in the 14-day window, not `v4_pools` rows, so the cap cannot lower it (a pool past the cap that trades becomes a row). To make it not understate a launchpad, `score` now reports per hook `max(pools with a snapshot, hooks.pools_total)`; for hooks without indexer rows nothing changes.
4. The nightly copy puts every `v4_pools` row of a known hook into `pools`, so "not referenced by `pools`" would protect every pool of the launchpad and the prune would delete nothing. The prune instead protects pools with any activity (`pool_daily_onchain`, `pool_snapshots`, `pool_stats`, `pool_top_wallets`) and deletes an idle pool's `pools` row with its `v4_pools` row.
5. In swap scan mode most unknown pool ids are unhooked pools, so the resolver keeps a negative cache; it is cleared when the floor moves down (a prune of older rows). Topic mode is skipped on a chain with a capped hook (its pools past the cap are not in the id list).
6. `getLaunches` needs no change: `collapseLaunches` (package 6) already shows a hook once with "+N more pools". Pools past the cap appear only once they trade (as sampled rows, at their real Initialize time).

```python
def store_pools(conn: sa.Connection, chain_id: int, rows: list[dict], cap: int) -> tuple[list[dict], list[dict]]:
    """One page's hooked pools under the per-hook cap -> (stored, unstored). A hook keeps at most `cap` v4_pools rows, the
    first to arrive; past that its pools only add to hook_pool_counts.pools_total (every pool of the hook, stored or
    not). Runs inside the page's transaction, before the upsert, so a page that fails rolls its counters back too.
    A capped hook counts only blocks after its last_block: a page seen twice (re-backfill from 0) is counted once.
    cap <= 0: no new caps (hooks already capped keep counting)."""
    if not rows:
        return [], []
    by_hook: dict[str, list[dict]] = {}
    for r in rows:
        by_hook.setdefault(r["hook_address"], []).append(r)
    hooks = sorted(by_hook)
    counters = {}
    for i in range(0, len(hooks), CHUNK):
        for c in conn.execute(sa.select(hook_pool_counts).where(
                hook_pool_counts.c.chain_id == chain_id, hook_pool_counts.c.hook_address.in_(hooks[i:i + CHUNK]))):
            counters[c.hook_address] = c
    have: dict[str, int] = {}
    open_hooks = [h for h in hooks if h not in counters]
    if cap > 0:
        for i in range(0, len(open_hooks), CHUNK):
            have.update(conn.execute(sa.select(v4_pools.c.hook_address, sa.func.count()).where(
                v4_pools.c.chain_id == chain_id, v4_pools.c.hook_address.in_(open_hooks[i:i + CHUNK]))
                .group_by(v4_pools.c.hook_address)).all())
    stored, unstored, counts = [], [], []
    for h in hooks:
        rs, c = by_hook[h], counters.get(h)
        if c is not None:                      # past the cap: count what is new, store nothing
            fresh = [r for r in rs if c.last_block is None or (r["block_number"] or 0) > c.last_block]
            if fresh:
                unstored += fresh
                counts.append(_counted(chain_id, h, c.pools_total, c.first_block, c.last_block, c.last_seen, fresh))
            continue
        n = have.get(h, 0)
        if cap <= 0 or n + len(rs) <= cap:
            stored += rs
            continue
        # crossing the cap. A row already stored (this page seen before) is neither stored again nor counted twice.
        ids, seen = [r["pool_id"] for r in rs], set()
        for i in range(0, len(ids), CHUNK):
            seen.update(conn.execute(sa.select(v4_pools.c.pool_id).where(
                v4_pools.c.chain_id == chain_id, v4_pools.c.pool_id.in_(ids[i:i + CHUNK]))).scalars())
        new = [r for r in rs if r["pool_id"] not in seen]
        room = max(cap - n, 0)
        stored += new[:room]
        over = new[room:]
        if over:
            unstored += over
            last = max((r["block_number"] for r in rs if r.get("block_number") is not None), default=None)
            seen_at = max((as_utc(r["block_time"]) for r in rs if r.get("block_time") is not None), default=None)
            counts.append(_counted(chain_id, h, n + len(new) - len(over), None, last, seen_at, over))
    upsert(conn, hook_pool_counts, counts, keys=["chain_id", "hook_address"])
    upsert_pools(conn, stored)
    return stored, unstored


def _counted(chain_id: int, hook: str, total: int, first, last, seen_at, rows: list[dict]) -> dict:
    """The hook_pool_counts row after counting `rows` (pools of the hook that are not stored)."""
    blocks = [r["block_number"] for r in rows if r.get("block_number") is not None]
    times = [as_utc(r["block_time"]) for r in rows if r.get("block_time") is not None]
    firsts, lasts = [b for b in (first, *blocks) if b is not None], [b for b in (last, *blocks) if b is not None]
    seens = [t for t in (as_utc(seen_at), *times) if t is not None]
    return {"chain_id": chain_id, "hook_address": hook, "pools_total": total + len(rows),
            "first_block": min(firsts) if firsts else None, "last_block": max(lasts) if lasts else None,
            "last_seen": max(seens) if seens else None}


def capped_floor(conn: sa.Connection, chain_id: int) -> int | None:
    """None: no hook on this chain is past the cap, so every hooked pool is a row. Else the oldest block a hooked pool
    that is not a row can have (where the lookup by pool id starts)."""
    n, first = conn.execute(sa.select(sa.func.count(), sa.func.min(hook_pool_counts.c.first_block))
                            .where(hook_pool_counts.c.chain_id == chain_id)).one()
    return None if not n else (first or 0)
```

```python
class LookupBudget(RuntimeError):
    """This loop's HyperSync budget for pool lookups is spent; the swap page waits for the next loop."""


class PoolResolver:
    """Keys of hooked pools that are not v4_pools rows (past their hook's cap, or pruned), for when one of them swaps.
    One per chain, kept by the Runner across loops. First `recent` (rows this process left out of v4_pools, the newest
    RECENT_MAX), then one HyperSync Initialize query by pool id (topic1) over [floor, page end) per `topic_chunk` ids, at
    most `pool_lookups` calls per loop. `absent` remembers ids that are not hooked pools (unhooked pools are most of a
    scan page); it is only valid for the floor it was built with, so it is cleared when the floor moves down."""
    RECENT_MAX = 50_000
    ABSENT_MAX = 1_000_000

    def __init__(self):
        self.recent: dict[str, dict] = {}
        self.absent: set[str] = set()
        self.absent_floor: int | None = None
        self.calls = 0

    def remember(self, rows) -> None:
        for r in rows:
            self.recent[r["pool_id"]] = r
        if len(self.recent) > self.RECENT_MAX:          # keep the newest half
            self.recent = dict(list(self.recent.items())[-(self.RECENT_MAX // 2):])

    def resolve(self, hs: HyperSync, chain: IndexedChain, ids, floor: int, to_block: int, settings: Settings) -> dict[str, dict]:
        """-> {pool_id: v4_pools row} for the ids that are hooked pools. A swap at a block below to_block means the pool
        was initialized below it, so one scan of [floor, to_block) settles every id it asked for."""
        if self.absent_floor is None or floor < self.absent_floor:
            self.absent.clear()
            self.absent_floor = floor
        found = {i: self.recent[i] for i in ids if i in self.recent}
        need = sorted(i for i in ids if i not in found and i not in self.absent)
        for k in range(0, len(need), settings.topic_chunk):
            if self.calls >= settings.pool_lookups:
                raise LookupBudget(f"pool lookup budget spent ({self.calls} calls), {len(need) - k} ids left")
            chunk, got, cur = need[k:k + settings.topic_chunk], {}, floor
            while cur < to_block:
                logs, blocks, _, nb, _ = page(hs.query(initialize_by_id_query(chain.pool_manager, cur, to_block, chunk)))
                self.calls += 1
                if nb is None or nb <= cur:
                    raise RuntimeError(f"HyperSync made no progress at block {cur} (next_block={nb})")
                for r in hooked_pools_from_page(chain.chain_id, logs, blocks):
                    got[r["pool_id"]] = r
                cur = nb
            self.remember(got.values())
            found.update(got)
            self.absent.update(i for i in chunk if i not in got)
        if len(self.absent) > self.ABSENT_MAX:
            self.absent.clear()
        return found
```

### Task 3b: Second cap on late rows; their usage is never lost (coordinator, mid-task)

```python
def _admit_late(engine, chain, late, agg, settings, st):
    with engine.connect() as conn:
        counters = store.hook_counters(conn, chain.chain_id, {r["hook_address"] for r in late.values()})
    free = {h: settings.sampled_per_hook - (c.sampled_total or 0) for h, c in counters.items()}
    rows, adds = [], {}
    for p, r in sorted(late.items(), key=lambda kv: (-agg.best.get(kv[0], -1.0), kv[0])):   # biggest swap first
        h = r["hook_address"]
        if h not in counters:                    # not a capped hook (a gap in Initialize history): a plain row
            rows.append(r)
            continue
        a = adds.setdefault(h, [0, 0, 0.0])
        if p in agg.best and agg.best[p] >= settings.late_min_usd and free[h] > 0:
            rows.append(r); free[h] -= 1; a[0] += 1
        else:
            n, v = agg.fold(p, hook_pool_id(h)); a[1] += n; a[2] += v
    return rows, adds
```

```python
"""python -m bait.indexer prune-pools --dry-run | --yes [--keep N] [--chains ...] [--lock-wait S]

One-time trim of v4_pools for hooks that already hold more than N rows (a launchpad's one pool per coin), written before
the per-hook cap (INDEXER_POOLS_PER_HOOK). Per (chain, hook) over N it keeps the newest N rows by block and every pool with
any activity (rows in pool_daily_onchain, pool_snapshots, pool_stats or pool_top_wallets), and deletes the rest together
with their `pools` rows (the nightly copy put every pool of a known hook there). hook_pool_counts records the hook's true
pool count before the first delete, so nothing but the rows is lost; a deleted pool that swaps later comes back as a
sampled row. --yes works per chain under the indexer's advisory lock (bait-indexer:<chain_id>), BATCH rows per
transaction, and stops between batches on SIGTERM. It does not VACUUM: Postgres autovacuum makes the space reusable, and
the volume does not shrink.
"""
from __future__ import annotations

import argparse
import logging
import os
import signal
import time
from dataclasses import dataclass
from datetime import datetime

import sqlalchemy as sa

from .. import db
from ..db import hook_pool_counts, pool_daily_onchain, pool_snapshots, pool_stats, pool_top_wallets, pools, upsert, v4_pools
from .chains import select_chains
from .core import _env_int

log = logging.getLogger("bait.indexer")

BATCH = 5000
ROW_BYTES = 550              # per-row estimate where Postgres cannot say (SQLite, a table never analyzed)
ACTIVITY = (pool_daily_onchain, pool_snapshots, pool_stats, pool_top_wallets)


@dataclass
class Over:
    hook: str
    rows: int                # v4_pools rows of the hook
    last: int | None         # newest block among them
    seen: datetime | None    # newest block time among them
    cut: tuple[int, str]     # (block, pool id) of the newest row that is not kept


def _idle() -> list:
    return [~sa.exists().where(t.c.chain_id == v4_pools.c.chain_id, t.c.pool_id == v4_pools.c.pool_id) for t in ACTIVITY]


def _candidates(chain_id: int, o: Over) -> list:
    return [v4_pools.c.chain_id == chain_id, v4_pools.c.hook_address == o.hook, v4_pools.c.block_number.is_not(None),
            sa.tuple_(v4_pools.c.block_number, v4_pools.c.pool_id) <= sa.tuple_(sa.literal(o.cut[0]), sa.literal(o.cut[1])),
            *_idle()]


def hooks_over(conn, chain_id: int, keep: int) -> list[Over]:
    out = []
    n = sa.func.count()
    for r in conn.execute(sa.select(v4_pools.c.hook_address, n.label("n"), sa.func.max(v4_pools.c.block_number).label("last"),
                                    sa.func.max(v4_pools.c.block_time).label("seen"))
                          .where(v4_pools.c.chain_id == chain_id).group_by(v4_pools.c.hook_address)
                          .having(n > keep).order_by(n.desc())):
        cut = conn.execute(sa.select(v4_pools.c.block_number, v4_pools.c.pool_id).where(
            v4_pools.c.chain_id == chain_id, v4_pools.c.hook_address == r.hook_address, v4_pools.c.block_number.is_not(None))
            .order_by(v4_pools.c.block_number.desc(), v4_pools.c.pool_id.desc()).offset(keep).limit(1)).first()
        if cut is not None:
            out.append(Over(r.hook_address, r.n, r.last, db.as_utc(r.seen), (cut.block_number, cut.pool_id)))
    return out


def _db_bytes(engine) -> int | None:
    if engine.dialect.name != "postgresql":
        return None
    with engine.connect() as c:
        return c.execute(sa.text("SELECT pg_database_size(current_database())")).scalar_one()


def _row_bytes(engine, table: str) -> float:
    """Table + index + TOAST bytes per row (pg_class.reltuples), else ROW_BYTES."""
    if engine.dialect.name != "postgresql":
        return ROW_BYTES
    with engine.connect() as c:
        r = c.execute(sa.text("SELECT pg_total_relation_size(c.oid), c.reltuples FROM pg_class c WHERE c.oid = to_regclass(:t)"),
                      {"t": table}).first()
    return r[0] / r[1] if r and r[1] and r[1] > 0 else ROW_BYTES


def _mb(n) -> str:
    return "?" if n is None else f"{n / 1024 ** 2:.1f} MB"


def _lock(engine, chain_id: int, wait: float, stop):
    deadline = time.monotonic() + wait
    while True:
        lock = db.try_advisory_lock(engine, f"bait-indexer:{chain_id}")
        if lock is not None or time.monotonic() >= deadline or stop():
            return lock
        time.sleep(min(5.0, max(0.0, deadline - time.monotonic())))


def _prune_hook(engine, chain_id: int, o: Over, batch: int, stop, out: dict) -> int:
    deleted, last = 0, None
    while not stop():
        with engine.begin() as conn:
            q = sa.select(v4_pools.c.pool_id, v4_pools.c.block_number).where(*_candidates(chain_id, o))
            if last is not None:
                q = q.where(sa.tuple_(v4_pools.c.block_number, v4_pools.c.pool_id) > sa.tuple_(sa.literal(last[0]), sa.literal(last[1])))
            rows = conn.execute(q.order_by(v4_pools.c.block_number, v4_pools.c.pool_id).limit(batch)).all()
            if not rows:
                break
            last = (rows[-1].block_number, rows[-1].pool_id)
            gone = conn.execute(sa.delete(v4_pools).where(v4_pools.c.chain_id == chain_id,
                                                          v4_pools.c.pool_id.in_([r.pool_id for r in rows]), *_idle())
                                .returning(v4_pools.c.pool_id, v4_pools.c.block_number)).all()
            if not gone:
                continue
            ids = [g.pool_id for g in gone]
            out["pools_rows"] += conn.execute(sa.delete(pools).where(pools.c.chain_id == chain_id, pools.c.pool_id.in_(ids))).rowcount or 0
            first = min(g.block_number for g in gone)
            c = conn.execute(sa.select(hook_pool_counts).where(hook_pool_counts.c.chain_id == chain_id,
                                                               hook_pool_counts.c.hook_address == o.hook)).first()
            upsert(conn, hook_pool_counts, [{
                "chain_id": chain_id, "hook_address": o.hook, "pools_total": max(o.rows, c.pools_total if c else 0),
                "first_block": min(first, c.first_block) if c and c.first_block is not None else first,
                "last_block": c.last_block if c and c.last_block is not None else o.last,
                "last_seen": c.last_seen if c and c.last_seen is not None else o.seen}], keys=["chain_id", "hook_address"])
            deleted += len(gone)
            out["batches"] += 1
    return deleted


def prune_pools(engine, keep: int, apply: bool, chain_ids: list[int], batch: int = BATCH, lock_wait: float = 600.0,
                should_stop=None) -> dict:
    stop = should_stop or (lambda: False)
    out = {"hooks": 0, "rows": 0, "pools_rows": 0, "est_bytes": 0, "batches": 0, "locked": [], "db_before": _db_bytes(engine),
           "db_after": None}
    log.info("prune-pools %s keep=%d chains=%s database=%s", "apply" if apply else "dry run", keep,
             ",".join(map(str, chain_ids)), _mb(out["db_before"]))
    v4_bytes, pools_bytes = _row_bytes(engine, "v4_pools"), _row_bytes(engine, "pools")
    for cid in chain_ids:
        if not apply:
            with engine.connect() as conn:
                for o in hooks_over(conn, cid, keep):
                    n, with_pools = conn.execute(sa.select(sa.func.count(), sa.func.count(pools.c.pool_id)).select_from(
                        v4_pools.outerjoin(pools, (pools.c.chain_id == v4_pools.c.chain_id) & (pools.c.pool_id == v4_pools.c.pool_id)))
                        .where(*_candidates(cid, o))).one()
                    est = int(n * v4_bytes + with_pools * pools_bytes)
                    out["hooks"] += 1
                    out["rows"] += n
                    out["pools_rows"] += with_pools
                    out["est_bytes"] += est
                    log.info("prune-pools dry run chain_id=%d hook=%s rows=%d keep=%d delete=%d pools_rows=%d est=%s",
                             cid, o.hook, o.rows, keep, n, with_pools, _mb(est))
            continue
        lock = _lock(engine, cid, lock_wait, stop)
        if lock is None:
            out["locked"].append(cid)
            log.warning("prune-pools chain_id=%d: the indexer holds bait-indexer:%d; chain skipped", cid, cid)
            continue
        try:
            with engine.connect() as conn:
                over = hooks_over(conn, cid, keep)
            for o in over:
                if stop():
                    break
                n = _prune_hook(engine, cid, o, batch, stop, out)
                out["hooks"] += 1
                out["rows"] += n
                out["est_bytes"] += int(n * v4_bytes)
                log.info("prune-pools chain_id=%d hook=%s rows=%d keep=%d deleted=%d", cid, o.hook, o.rows, keep, n)
        finally:
            lock.close()
    if apply:
        out["db_after"] = _db_bytes(engine)
    log.info("prune-pools %s: hooks=%d rows=%d pools_rows=%d batches=%d est=%s database %s -> %s (space returns to Postgres "
             "after autovacuum; the volume does not shrink)", "done" if apply else "dry run", out["hooks"], out["rows"],
             out["pools_rows"], out["batches"], _mb(out["est_bytes"]), _mb(out["db_before"]), _mb(out["db_after"]))
    return out


def main(argv: list[str]) -> int:
    ap = argparse.ArgumentParser(prog="python -m bait.indexer prune-pools",
                                 description="One-time trim of v4_pools rows of hooks past the per-hook cap.")
    mode = ap.add_mutually_exclusive_group(required=True)
    mode.add_argument("--dry-run", action="store_true", help="per-hook counts and estimated bytes; changes nothing")
    mode.add_argument("--yes", action="store_true", help="delete, per chain under the indexer's lock")
    ap.add_argument("--keep", type=int, default=_env_int("INDEXER_POOLS_PER_HOOK", 2000),
                    help="newest rows kept per hook (default INDEXER_POOLS_PER_HOOK, 2000)")
    ap.add_argument("--chains", default=os.environ.get("INDEXER_CHAINS"), help="comma slugs or chain ids (default all)")
    ap.add_argument("--database-url", default=None)
    ap.add_argument("--lock-wait", type=float, default=600.0, help="seconds to wait for each chain's indexer lock")
    args = ap.parse_args(argv)
    if args.keep < 1:
        ap.error("--keep must be at least 1")
    try:
        chains = select_chains(args.chains)
    except ValueError as e:
        log.error("%s", e)
        return 2
    engine = db.make_engine(args.database_url)
    db.create_all(engine)                      # hook_pool_counts, on a database the new indexer has not migrated yet
    stop = {"flag": False}

    def _stop(signum, _frame):
        log.info("signal %s: stopping after the current batch", signum)
        stop["flag"] = True
    old = {s: signal.signal(s, _stop) for s in (signal.SIGTERM, signal.SIGINT)}
    try:
        out = prune_pools(engine, args.keep, args.yes, [c.chain_id for c in chains], lock_wait=args.lock_wait,
                          should_stop=lambda: stop["flag"])
    finally:
        for s, h in old.items():
            signal.signal(s, h)
    return 3 if out["locked"] else 0
```
